Phase 1: Storage Helpers

Project: Archive Raw Box Scores Phase: 1 of 3 Depends on: None (first phase)
⚠️ Prerequisite: The ncaa-raw-games Supabase Storage bucket must already exist and game JSON files must be present at paths like MSO/1/2025/12-15.json. This was created by the archive-raw-json project.

Overview

Extends src/lib/server/ncaa-archive.ts with three new exported functions for box score storage operations. These are pure server-side helpers with no UI — the API endpoints in Phase 2 and the admin UI in Phase 3 both depend on them. All box score files live in the same ncaa-raw-games bucket under a boxscores/ subfolder within the season prefix.

What Will Be Built

Add three functions to src/lib/server/ncaa-archive.ts (append to the existing file — do not modify the existing game helpers):

1. boxScorePath(sportCode, division, seasonYear, contestId)

Pure path builder. Returns the Storage path for a box score file.

export function boxScorePath(
  sportCode: string,
  division: number,
  seasonYear: number,
  contestId: string | number
): string {
  return `${sportCode}/${division}/${seasonYear}/boxscores/${contestId}.json`;
}

2. saveBoxScoreJson(sportCode, division, seasonYear, contestId, data)

Uploads a box score response to Storage, overwriting any existing file.

export async function saveBoxScoreJson(
  sportCode: string,
  division: number,
  seasonYear: number,
  contestId: string | number,
  data: unknown
): Promise<{ path: string }> {
  const path = boxScorePath(sportCode, division, seasonYear, contestId);
  const body = JSON.stringify(data, null, 2);
  const { error } = await supabaseAdmin.storage
    .from(BUCKET)
    .upload(path, body, { contentType: 'application/json', upsert: true });
  if (error) throw new Error(`Storage upload failed for ${path}: ${error.message}`);
  return { path };
}

3. listArchivedBoxScoreIds(sportCode, division, seasonYear)

Lists all archived box score files for a season and returns their contest IDs as strings. Uses a high limit (2000) to cover a full season without pagination — a D-I men's season has ~1,000–1,500 games.

export async function listArchivedBoxScoreIds(
  sportCode: string,
  division: number,
  seasonYear: number
): Promise<string[]> {
  const prefix = `${sportCode}/${division}/${seasonYear}/boxscores`;
  const { data, error } = await supabaseAdmin.storage
    .from(BUCKET)
    .list(prefix, { limit: 2000 });
  if (error) throw new Error(`Storage list failed for ${prefix}: ${error.message}`);
  return (data ?? [])
    .filter(f => f.name.endsWith('.json'))
    .map(f => f.name.replace('.json', ''))
    .sort();
}

4. readGameContestIds(sportCode, division, seasonYear, contestDate)

Downloads a game JSON file from Storage (already archived by the game scraper), parses it, and returns the list of contest IDs found. Returns an empty array if the file does not exist (no games on that date).

export async function readGameContestIds(
  sportCode: string,
  division: number,
  seasonYear: number,
  contestDate: string // YYYY-MM-DD
): Promise<string[]> {
  const path = archivePath(sportCode, division, seasonYear, contestDate);
  const { data, error } = await supabaseAdmin.storage.from(BUCKET).download(path);
  if (error) {
    // File not found is not an error — some dates have no game file
    if (error.message.includes('Not Found') || error.message.includes('404')) return [];
    throw new Error(`Storage download failed for ${path}: ${error.message}`);
  }
  const text = await (data as Blob).text();
  const json = JSON.parse(text) as { data?: { contests?: { contestId: number | string }[] } };
  return (json?.data?.contests ?? []).map(c => String(c.contestId));
}
Note on Supabase Storage download: The method returns a Blob. Call (data as Blob).text() to get the string, then JSON.parse(). This is different from the upload path which accepts a string body directly.

Implementation Notes

  • All four helpers go in src/lib/server/ncaa-archive.ts, appended after the existing three exports. Do not modify the existing archivePath, saveContestJson, or listArchivedDates functions.
  • The BUCKET constant ('ncaa-raw-games') is already defined in the file — reuse it.
  • The archivePath function is already exported from the file — call it directly in readGameContestIds to derive the game file path.
  • Box score files are stored at {sportCode}/{division}/{seasonYear}/boxscores/{contestId}.json, so they live in a subfolder of the season prefix rather than alongside the date files. The listArchivedDates function already filters by .endsWith('.json') so it will not accidentally pick up box score files (they are in a deeper prefix).
  • contestId is typed as string | number because the raw JSON returns it as a number (6500844) but it is always converted to a string for path and URL use.
