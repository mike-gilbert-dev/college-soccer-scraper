Phase 4: Admin UI

Project: Sport-Specific Seasons Phase: 4 of 4 Depends on: Phase 1, 3 complete
⚠️ Prerequisite: Phase 1 (Schema Migration) and Phase 3 (Admin API Endpoints) must be complete before this phase. The Manage Seasons form calls /api/seasons; the tool dropdowns must match what the endpoints now expect.

Overview

Updates the admin page's "Manage Seasons" section and all tool-form season dropdowns to handle sport+division-specific seasons. The Manage Seasons table gains Sport and Division columns; its add/edit form gains gender and division selectors. All five tool forms (backfill, missing dates, missing games, archive raw games, archive box scores, ingest archives) gain a reactive filter so their season dropdown only shows seasons matching the currently selected sport and division.

What Will Be Built

All changes are confined to src/routes/admin/+page.svelte and src/routes/admin/+page.server.ts.

1. Update the server load (+page.server.ts)

The server load currently fetches all seasons for the allSeasons list. Update the SELECT to include sport_code and division:

// BEFORE
supabase.from('seasons').select('id, label, start_date, end_date').order('start_date', { ascending: false })

// AFTER
supabase.from('seasons').select('id, label, start_date, end_date, sport_code, division').order('label', { ascending: false }).order('sport_code').order('division')

Update the SeasonRow type to include sport_code: string and division: number.

2. Season dropdown filtering in all tool forms

Each tool form has its own sport selector (e.g., backfillSport, archiveSport, bsSport, igSport) and division selector. The season dropdown for each tool currently shows all seasons. Add a $derived filtered list per tool:

// Example for backfill tool (replicate for all 6 tools)
const backfillSeasons = $derived(
  (data.seasons as SeasonRow[]).filter(s =>
    s.sport_code === backfillSport && s.division === Number(backfillDivision)
  )
);

Then bind each tool's season <Select> to its filtered list instead of data.seasons.

The six tool prefixes and their sport/division state variables are:

  • Backfill: backfillSport, backfillDivision → backfillSeasons
  • Missing Dates: read the file to find the prefixed sport/division state variables
  • Missing Games: same
  • Archive Raw Games: archiveSport, archiveDivision → archiveSeasons
  • Archive Box Scores: bsSport, bsDivision → bsSeasons
  • Ingest Archives: igSport, igDivision → igFilteredSeasons (avoid naming it igSeasons since that might conflict with existing state)
ℹ️ When the sport or division changes and the currently selected season label no longer exists in the filtered list, reset the season state variable to the first item in the filtered list (or empty string). Add this reset logic inside the existing $effect blocks that already watch sport/division changes, or add a new $effect per tool.

3. Update the Manage Seasons table

The seasons table in the Manage Seasons view currently shows Label, Start Date, End Date, and actions. Add Sport and Division columns:

  • Sport column: display 'Men' for sport_code === 'MSO', 'Women' for 'WSO'
  • Division column: display s.division
  • Sort order in the display: group by label, then by sport (Men first), then by division ascending. The server load's order-by handles this.

4. Update the Add Season form

The "Add New Season" form below the table currently has inputs for Label, Start Date, and End Date. Add two new selectors before the date inputs:

  • Sport: Select with options Men (MSO) / Women (WSO), bound to a new newSeasonSport state variable (default 'MSO')
  • Division: Select with options 1 / 2 / 3, bound to a new newSeasonDivision state variable (default 1)

Include sport_code and division in the POST body when submitting:

const body = {
  label:       newSeasonLabel.trim(),
  start_date:  newSeasonStart,
  end_date:    newSeasonEnd,
  sport_code:  newSeasonSport,
  division:    Number(newSeasonDivision)
};

After a successful add, push the new row into data.seasons (or re-fetch) so the table and all dropdowns update reactively.

5. Update the Edit Season inline form

The inline edit row currently edits Label, Start Date, and End Date. Add Sport and Division selectors to the edit form as well, pre-populated from the row being edited. Include them in the PATCH body.

Implementation Notes

  • Read the full script block of src/routes/admin/+page.svelte before making any changes — the file is large and the variable names for each tool's sport/division state must be confirmed before writing derived variables.
  • The SeasonRow type is defined in the script block and used in $effect blocks for auto-filling dates. Add sport_code and division to this type.
  • The auto-fill $effect blocks that set start_date/end_date when the season changes use (data.seasons as SeasonRow[]).find(s => s.label === igSeason). After the change, the season dropdown will only show seasons matching the current sport+division, so the find will still work — no change needed to those effects.
  • Follow the existing Svelte 5 runes patterns throughout: use $derived for the filtered season lists, not $effect.
  • Use Flowbite Svelte <Select> components for the new Sport and Division fields in the add/edit form, consistent with the existing form fields.
  • The Manage Seasons table currently shows all seasons. After this change it will show 6× as many rows — sorting by label then sport then division keeps it readable.

How to Validate

  1. Start dev server: npm run dev, navigate to http://localhost:5173/admin.
  2. Click "Manage Seasons" in the sidebar — confirm the table shows Sport and Division columns, with 6 rows per season label.
  3. Fill in the Add Season form with Women / Division 2 / label "2025-2026" / any dates — confirm a 400 error is returned (duplicate unique key) and that a new label with valid dates creates a new row.
  4. Click Edit on any season row — confirm the Sport and Division fields are pre-populated and can be changed.
  5. Navigate to "Historic Backfill". Select Men / D1 — confirm the season dropdown shows only MSO D1 seasons. Switch to Women / D1 — confirm the season dropdown now shows only WSO D1 seasons.
  6. Repeat step 5 for Archive Raw Games, Archive Box Scores, and Ingest Archives.
  7. Select a sport+division combination that has a season, then switch division to one that has the same label — confirm the season field resets correctly.
  8. Run a Check Status on Ingest Archives for both MSO D1 and WSO D1 — confirm both return without error (WSO D1 game count will be 0).
  9. Run npm run check — 0 errors.
