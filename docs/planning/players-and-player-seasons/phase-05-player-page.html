Phase 5: Player Detail Page

Project: Players & Player Seasons  |  Depends on: Phase 4 (team roster links here)

Build the player detail page at /players/[ncaa_player_id]. Shows the player's career overview (season stats by year) and a per-game log (game log table). The player is linked to from the team roster page built in Phase 4. Includes a breadcrumb trail back to the team page.

Completion Criteria

  • Route src/routes/players/[ncaa_player_id]/+page.server.ts loads: player record, all player_seasons with joined team and season data, all player_game_stats joined with game data
  • If no player record exists for the given ncaa_player_id, the server returns a 404 error
  • Page header shows: player full name, position badge, and class year (from their most recent player_season)
  • Career stats table shows one row per season: Year, Team (link to /teams/[ncaa_team_id]), GP, G, A, Pts, Shots, SOG, Min; goalkeepers show Sv, GA, SO instead of Shots/SOG
  • Game log table shows one row per game: Date, Opponent (with link to that team), Score (home vs away), Min, G, A, Shots; goalkeepers show Sv, GA, SO
  • Game log is sorted by contest_date descending (most recent first)
  • If a player has stats in multiple seasons (career), the career table shows all seasons
  • If no stats exist for the player yet, both tables show a graceful empty state
  • Breadcrumb at top of page: "Teams / [Team Name] / [Player Name]" — team link uses the player's most recent team and preserves sport/division/season params

Implementation Notes

Server load (src/routes/players/[ncaa_player_id]/+page.server.ts)

import { error } from '@sveltejs/kit';
import type { PageServerLoad } from './$types';
import { supabaseAdmin } from '$lib/server/supabase-admin';

export const load: PageServerLoad = async ({ params, url }) => {
  const sportCode  = url.searchParams.get('sport')    ?? 'MSO';
  const division   = parseInt(url.searchParams.get('division') ?? '1', 10);
  const seasonYear = parseInt(url.searchParams.get('season')   ?? '2025', 10);

  // Player master record
  const { data: player } = await supabaseAdmin
    .from('players')
    .select('id, ncaa_player_id, name')
    .eq('ncaa_player_id', params.ncaa_player_id)
    .single();

  if (!player) error(404, 'Player not found');

  // All seasons the player has appeared in
  const { data: careerSeasons } = await supabaseAdmin
    .from('player_season_stats')
    .select(`
      player_season_id, team_season_id, jersey_number, position, class_year,
      games_played, minutes_played, goals, assists, points, shots, shots_on_goal,
      fouls, yellow_cards, red_cards, gk_saves, gk_goals_against, gk_shutouts,
      team_season:team_seasons (
        division, sport_code,
        season:seasons ( year ),
        team:teams ( ncaa_team_id, name )
      )
    `)
    .eq('player_id', player.id)
    .order('year', { foreignTable: 'team_seasons.seasons' });

  // Per-game stats
  const { data: gameLog } = await supabaseAdmin
    .from('player_game_stats')
    .select(`
      id, minutes_played, goals, assists, shots, shots_on_goal,
      fouls_committed, yellow_cards, red_cards,
      gk_saves, gk_goals_against, gk_shutout,
      game:games (
        id, ncaa_contest_id, contest_date, home_score, away_score, sport_code,
        home_team_season:team_seasons!home_team_season_id (
          team:teams ( ncaa_team_id, name )
        ),
        away_team_season:team_seasons!away_team_season_id (
          team:teams ( ncaa_team_id, name )
        )
      ),
      player_season:player_seasons (
        team_season_id,
        team_season:team_seasons ( team:teams ( ncaa_team_id, name ) )
      )
    `)
    .in('player_season_id',
      (careerSeasons ?? []).map(s => s.player_season_id)
    )
    .order('contest_date', { foreignTable: 'games', ascending: false });

  return {
    player,
    careerSeasons: careerSeasons ?? [],
    gameLog: gameLog ?? [],
    sportCode, division, seasonYear
  };
};
The nested select depth here (player_game_stats → games → team_seasons → teams) is supported by Supabase PostgREST. If the query becomes too complex, split it into two separate queries (one for career stats, one for game log) and join in the load function.

Determining the breadcrumb team

Use the most recent player_season's team for the breadcrumb. "Most recent" = highest season year from careerSeasons:

const mostRecentSeason = $derived(
  data.careerSeasons.length > 0
    ? [...data.careerSeasons].sort((a, b) =>
        (b.team_season?.season?.year ?? 0) - (a.team_season?.season?.year ?? 0)
      )[0]
    : null
);

const breadcrumbTeam = $derived(mostRecentSeason?.team_season?.team);

Game log: opponent and score display

For each game in the game log, you need to know which team the player was on (to determine "opponent"). The player's team is available via player_season.team_season.team. The opponent is the other team in the game.

function getOpponent(game: GameRow, playerTeamNcaaId: string) {
  const home = game.home_team_season?.team;
  const away = game.away_team_season?.team;
  if (home?.ncaa_team_id === playerTeamNcaaId) return away;
  return home;
}

function getScore(game: GameRow, playerTeamNcaaId: string) {
  const isHome = game.home_team_season?.team?.ncaa_team_id === playerTeamNcaaId;
  return isHome
    ? `${game.home_score}–${game.away_score}`
    : `${game.away_score}–${game.home_score}`;
}

GK vs outfield column visibility

Determine if the player is a goalkeeper from their most common position in careerSeasons or from the most recent player_season's position field. If position === 'GK', show GK columns (Sv, GA, SO) and hide Shots/SOG; otherwise show Shots/SOG and hide GK columns. A simpler approach: always show all columns and display — for null values.

TypeScript types
