Phase 2: API Endpoints

Project: Ingest Raw Archives Phase: 2 of 3 Depends on: Phase 1 complete
⚠️ Prerequisite: Phase 1 (Storage Read Helpers) must be complete. readGameContests, readStoredBoxScore, and StoredBoxScoreResult must be exported from ncaa-archive.ts before building these endpoints.

Overview

Creates two SvelteKit server routes under src/routes/api/ingest/. The POST endpoint processes one date: it reads the archived game JSON and box score files from Storage, then upserts all corresponding records into the database (teams, team_seasons, games, players, player_seasons, player_game_stats). The GET endpoint returns counts of archived files and existing DB records for the status check UI. No live NCAA API calls are made by either endpoint.

What Will Be Built

1. src/routes/api/ingest/date/+server.ts — POST

Processes all contests for one date. Reads from Storage, writes to the database. Treats the archived JSON as the single source of truth.

Request body (JSON):

{
  sportCode:   string,   // 'MSO' | 'WSO'
  division:    number,   // 1 | 2 | 3
  seasonLabel: string,   // e.g. '2025-2026'
  contestDate: string    // YYYY-MM-DD
}

Success response (200):

{
  contestDate:         string,
  contestsFound:       number,   // contests in the game file (0 if no file)
  gamesUpserted:       number,
  teamsUpserted:       number,
  playerStatsUpserted: number,
  boxScoresCleared:    number,   // games where player_game_stats were deleted (empty box score)
  errors:              { contestId: string; message: string }[]
}

Server logic (pseudocode):

export const POST: RequestHandler = async ({ request, locals }) => {
  const { user } = await locals.safeGetSession();
  if (!user) error(401, 'Unauthorized');

  const { sportCode, division, seasonLabel, contestDate } = await request.json();

  // 1. Season lookup
  const { data: season } = await supabaseAdmin
    .from('seasons').select('id, year').eq('label', seasonLabel).single();
  if (!season) return json({ error: `Season not found: ${seasonLabel}` }, { status: 400 });

  // 2. Read contests from Storage
  const contests = await readGameContests(sportCode, division, season.year, contestDate);
  if (contests.length === 0) {
    return json({ contestDate, contestsFound: 0, gamesUpserted: 0, teamsUpserted: 0,
                  playerStatsUpserted: 0, boxScoresCleared: 0, errors: [] });
  }

  const results = {
    contestDate, contestsFound: contests.length,
    gamesUpserted: 0, teamsUpserted: 0,
    playerStatsUpserted: 0, boxScoresCleared: 0,
    errors: [] as { contestId: string; message: string }[]
  };

  // Inline helpers (see Implementation Notes)
  // upsertTeamSeason(teamData, seasonId) → number | null
  // captureTeamColorsFromBoxScore(boxScore) → void
  // upsertPlayerGameStats(boxScore, gameDbId, homeTeamSeasonId, awayTeamSeasonId)
  //   → { playersUpserted, statsUpserted }

  for (const contest of contests) {
    const homeData = contest.teams.find(t => t.isHome);
    const awayData = contest.teams.find(t => !t.isHome);
    if (!homeData || !awayData) continue;

    try {
      // 3. Upsert teams + team_seasons
      const [homeTeamSeasonId, awayTeamSeasonId] = await Promise.all([
        upsertTeamSeason(homeData, season.id),
        upsertTeamSeason(awayData, season.id)
      ]);
      if (!homeTeamSeasonId || !awayTeamSeasonId) continue;
      results.teamsUpserted += 2;

      // 4. Upsert game record
      const startTime = contest.startTimeEpoch
        ? new Date(contest.startTimeEpoch * 1000).toISOString()
        : null;
      const { data: gameRow } = await supabaseAdmin
        .from('games')
        .upsert({
          ncaa_contest_id: String(contest.contestId),
          season_id:            season.id,
          contest_date:         contestDate,
          start_time:           startTime,
          home_team_season_id:  homeTeamSeasonId,
          away_team_season_id:  awayTeamSeasonId,
          home_score:           homeData.score,
          away_score:           awayData.score,
          status:               normalizeStatus(contest.statusCodeDisplay),
          neutral_site:         false,
          sport_code:           sportCode,
          division,
          broadcaster_name:     contest.broadcasterName ?? null,
          round_description:    contest.roundDescription ?? null,
          last_fetched_at:      new Date().toISOString()
        }, { onConflict: 'ncaa_contest_id' })
        .select('id')
        .single();

      if (gameRow) results.gamesUpserted++;
      if (!gameRow) continue;

      // 5. Box score: read from Storage and sync player_game_stats
      const bsResult = await readStoredBoxScore(
        sportCode, division, season.year, String(contest.contestId)
      );

      if (!bsResult.fileFound) {
        // No box score file archived yet — skip player stats, leave DB unchanged
      } else if (!bsResult.boxScore) {
        // File exists but NCAA returned no data (e.g. scheduled game) —
        // delete any stale player_game_stats to keep DB in sync with files
        await supabaseAdmin
          .from('player_game_stats')
          .delete()
          .eq('game_id', gameRow.id);
        results.boxScoresCleared++;
      } else {
        // Full box score available — update team colors and write player stats
        await captureTeamColorsFromBoxScore(bsResult.boxScore);
        const { statsUpserted } = await upsertPlayerGameStats(
          bsResult.boxScore, gameRow.id, homeTeamSeasonId, awayTeamSeasonId
        );
        results.playerStatsUpserted += statsUpserted;
      }
    } catch (e) {
      const msg = e instanceof Error ? e.message : String(e);
      results.errors.push({ contestId: String(contest.contestId), message: msg });
    }
  }

  return json(results);
};
No delays: Unlike the backfill, this endpoint makes no live NCAA API calls — it only reads from Supabase Storage and writes to the database. Do not add any sleep() calls. The client loops dates as fast as each POST resolves.
All game statuses: The backfill only fetches box scores for games with status final. This endpoint processes box scores for every contest regardless of status, because the archives already store box scores for scheduled and live games. A scheduled game's box score file will typically have data.boxscore === null, which triggers the boxScoresCleared path.

2. src/routes/api/ingest/status/+server.ts — GET

Returns three counts the UI displays after "Check status": how many game files are archived, how many box score files are archived, and how many games are already in the database for this sport/division/season. Also returns the season's date bounds.

Query parameters:

?sportCode=MSO&division=1&seasonLabel=2025-2026

Success response (200):

{
  archivedGameFiles: number,
  archivedBoxScores: number,
  dbGamesCount:      number,
  seasonYear:        number,
  startDate:         string,   // YYYY-MM-DD
  endDate:           string    // YYYY-MM-DD
}

Server logic (pseudocode):

export const GET: RequestHandler = async ({ url, locals }) => {
  const { user } = await locals.safeGetSession();
  if (!user) error(401, 'Unauthorized');

  const sportCode   = url.searchParams.get('sportCode')   ?? 'MSO';
  const division    = Number(url.searchParams.get('division') ?? 1);
  const seasonLabel = url.searchParams.get('seasonLabel') ?? '';
  if (!seasonLabel) error(400, 'seasonLabel is required');

  const { data: season } = await supabaseAdmin
    .from('seasons')
    .select('id, year, start_date, end_date')
    .eq('label', seasonLabel)
    .single();
  if (!season) error(400, `Season "${seasonLabel}" not found`);

  const [archivedDates, archivedBoxScoreIds, { count: dbGamesCount }] = await Promise.all([
    listArchivedDates(sportCode, division, season.year),
    listArchivedBoxScoreIds(sportCode, division, season.year),
    supabaseAdmin
      .from('games')
      .select('*', { count: 'exact', head: true })
      .eq('season_id', season.id)
      .eq('sport_code', sportCode)
      .eq('division', division)
  ]);

  return json({
    archivedGameFiles: archivedDates.length,
    archivedBoxScores: archivedBoxScoreIds.length,
    dbGamesCount:      dbGamesCount ?? 0,
    seasonYear:        season.year,
    startDate:         season.start_date,
    endDate:           season.end_date
  });
};

Implementation Notes

Inline helper functions

The POST endpoint needs three helper functions: upsertTeamSeason, captureTeamColorsFromBoxScore, and upsertPlayerGameStats. Copy these directly from src/routes/api/scrape/backfill/+server.ts and define them inline inside the POST handler (same pattern as the backfill). Do not extract them to a shared module — that is out of scope for this phase. The functions are identical in behavior; the only change is that upsertPlayerGameStats receives an NcaaBoxScore that was read from Storage rather than fetched live.

Imports

  • From $lib/server/ncaa-archive: readGameContests, readStoredBoxScore, listArchivedDates, listArchivedBoxScoreIds
  • From $lib/server/ncaa-api: normalizeStatus, syntheticPlayerId, type NcaaContestTeam, type NcaaBoxScore
  • From $lib/server/supabase-admin: supabaseAdmin
  • From @sveltejs/kit: json, error

player_game_stats deletion

When a box score file exists but data.boxscore is null, delete all player_game_stats rows for that game: supabaseAdmin.from('player_game_stats').delete().eq('game_id', gameRow.id). Do not delete players or player_seasons rows — those may have been created by other games and the ingest has no way of knowing.

Error isolation

Wrap the entire per-contest block in a try/catch so a single failed contest does not abort processing of the rest of the date. Push the error to results.errors and continue the loop. The date-level response always returns 200 — errors are surfaced in the errors array, not as HTTP error codes.

Key files to read before starting

  • src/routes/api/scrape/backfill/+server.ts — copy the three inline helper functions verbatim; understand the full upsert pattern before adapting it
  • src/routes/api/archive/boxscore/date/+server.ts — pattern for the POST endpoint shape (auth, season lookup, Storage helpers, error handling)
  • src/routes/api/archive/boxscore/status/+server.ts — pattern for the GET endpoint shape
  • src/lib/server/ncaa-archive.ts — confirm Phase 1 helpers are present before building

Completion Criteria

Every item below must be satisfied before proceeding to Phase 3.

  • POST /api/ingest/date returns 200 with { contestsFound, gamesUpserted, teamsUpserted, playerStatsUpserted, boxScoresCleared, errors } for a date with archived game and box score files
  • After a successful POST, the games appear in the database with the correct status matching what is in the archived game JSON (not hard-coded to 'final')
  • Posting a date with an archived game file but no box score files results in playerStatsUpserted: 0 and no error — games are upserted, player stats are skipped
  • Posting a date with no archived game file returns 200 with contestsFound: 0 and all counts zero
  • Posting the same date twice produces the same counts both times (upserts are idempotent)
  • GET /api/ingest/status returns 200 with archivedGameFiles, archivedBoxScores, dbGamesCount, startDate, endDate
  • After a POST, dbGamesCount from the GET endpoint reflects the newly upserted games
  • npm run check passes with no TypeScript errors

How to Validate

  1. Start the dev server: npm run dev. Navigate to /admin and log in (endpoints require auth).
  2. Create a smoke test script that replicates the endpoint logic directly (same approach as scripts/smoke-test-boxscore-endpoints.mjs), using a date known to have both a game file and box score files (e.g. 2025-12-15).
  3. Run the smoke test — expect contestsFound > 0, gamesUpserted > 0, teamsUpserted > 0, errors: [].
  4. Open Supabase Studio → Table Editor → games — confirm rows exist for the contest IDs from that date with the correct status value.
  5. If box scores are archived for that date, confirm player_game_stats rows exist for the inserted game IDs.
  6. Run the smoke test again — expect identical counts (idempotent).
  7. Test with an off-season date (e.g. 2025-01-01) — expect { contestsFound: 0 } with no errors.
  8. GET /api/ingest/status?sportCode=MSO&division=1&seasonLabel=2025-2026 and confirm dbGamesCount matches what you see in Supabase Studio.
